One pickup line for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty: a single line, 107 characters, spoken by a vending machine to a passing human — it only takes exact change, but for this one it would take a chance, and it wants to drop something sweet. `main.py` writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

The line:

> I only take exact change, but for you I'd take a chance — press B7 and let me drop something sweet for you.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
